# FLEXG PAGE — 페이지 빌더 데이터 바인딩 영역 화면설계

페이지 빌더 에디터에서 **오른쪽 패널의 [데이터] 탭**을 설계하는 기획 문서 프로토타입.
편집기를 실제로 눌러 요소를 골라 가면서, 각 영역의 기능 정의·규칙·예외 케이스를 옆에서 함께 읽는다.

> 작성 : 컨버전스 김하은 / 2026.09.09

## 무엇을 다루나

데이터 바인딩의 **동작 4단계**를 오른쪽 패널 [데이터] 탭 한 곳에서 잇는 화면으로 다시 구성한다.

| 단계 | 개선안이 정의한 것 | 이 프로토타입 |
| --- | --- | --- |
| 1 | 데이터 매핑 대상 설정 — 단일 요소(이미지·텍스트 등)와 그룹핑된 컨테이너 요소 중 매핑할 대상을 지정 | ① 선택 요소 |
| 2 | 데이터 소스 설정 — 연결할 상품 목록·카테고리·데이터 세트 등 매핑 소스를 설정 | ② 데이터 설정 › 반복 데이터 |
| 3 | 필드 매핑(반복·개별) — 반복 구조를 지정하거나 개별 요소에 속성 값(상품명·가격·썸네일)을 매핑 | ② 데이터 설정 › 개별 데이터 |
| 4 | 조건부 노출 및 포맷팅 — 값 유무에 따라 레이어를 표시·숨김하거나 형태를 다르게 처리 | 표시 조건까지만 · 포맷팅은 범위 밖 |

**설계 범위는 오른쪽 패널의 [데이터] 탭 한 영역**이고, 헤더 · 왼쪽 아이콘 줄 · 왼쪽 패널(페이지 목록·레이어) · 캔버스 · 같은 자리를 나눠 쓰는 [스타일]·[애니메이션] 탭은 지금 쓰는 기본 세팅값 그대로다. 데이터를 이을 때 무엇을 보며 작업하는지 맥락으로만 쓴다.

## 실행

```bash
npm install
npm run dev        # http://localhost:3000
```

| 열어볼 곳 | 무엇 |
| --- | --- |
| `/docs` | 기획 문서(좌 트리 · 중앙 프리뷰 · 우 설명) |
| `/docs/page-builder` | 에디터 화면 문서 — 상단 탭으로 스타일 · 애니메이션 · 데이터 전환 |
| `/docs/pages` | 작업페이지 한눈에 보기 |
| `/components` | 컴포넌트 표준(디자인 시스템) |

문서의 상단 탭을 누르면 프리뷰에 `?tab=` 이 실려 오른쪽 패널이 그 탭으로 열린다.
편집기라 요소가 촘촘해 **화면 위 번호 마커는 꺼 뒀다.** 설명 패널의 번호만 보고 읽는다.

## 정리한 판단

시안에 없거나 어긋나던 부분은 이렇게 정해서 문서와 화면에 반영했다.

| 항목 | 정한 것 |
| --- | --- |
| 표시 조건 자리 | 시안의 「데이터 연결 / 조건부 설정」 두 탭을 없애고, 반복 데이터·개별 데이터 각각의 아래에 붙임. 탭으로 갈리면 어느 데이터에 건 조건인지 알 수 없음 |
| 고른 요소 표시 | 시안의 「작업 창에서 선택됨」 카드를 빼고 목록 안 체크와 색으로만 표시. 같은 것이 두 번 나와 헷갈림 |
| 안 쓰는 쪽 처리 | 한쪽을 옅게 두는 대신 아예 잠그고, 왜 못 고르는지 칸 아래 한 줄로 알림 |
| 반복과 개별의 경계 | 그룹을 고르면 개별을, 낱개 요소를 고르면 반복을 잠금. 그룹은 값 하나를 갖지 않고 안에 든 자리마다 따로 이음 |
| 요소를 바꿨을 때 | 고른 값과 걸어 둔 반복을 함께 풀어, 잠긴 칸에 값이 남지 않게 함 |
| 조건 팝업 진입 | 새로 걸기와 고치기가 같은 팝업을 엶. 적용을 눌러야 반영되고, 취소하면 없던 일이 됨 |
| 요소를 고르는 길 | 캔버스 · 레이어 · 요소 목록 세 곳 어디서 골라도 결과가 같게 함 |
| 단일 요소 바인딩 테스트 | 반복 부모가 없는 낱개 자리를 점선 상자로 따로 둠. 반복 없이 개별 연결만 확인하는 자리 |
| 화면 위 번호 마커 | 편집기라 요소가 촘촘해 번호가 화면을 덮음. 끄고 설명 패널 번호만 씀 |
| PAGE 서비스 색 | 디자인시스템에 PAGE 컴포넌트도 토큰도 아직 없어, 색을 화면 파일 맨 위 한곳에 모으고 「디자인시스템 요청 대상」으로 표시 |

> 상태는 **작성중**. 개선안과 대조해 남은 것 — 반복 적용 후 그룹 안 요소에 상위 소스의 하위 항목만 나오게 하는 종속 규칙, 카테고리 기준 분기(카테고리 반복 → 기준 선택 → 카테고리 선택), 4단계의 포맷팅, 기존 기능(데이터 가져오기 · 내보내기 소스 · 무한 스크롤 · 최대 항목 수 · 대체 텍스트), 고른 항목을 따라가지 않는 반환값 미리보기, 같은 성격의 요소가 함께 골라지는 선택 단위.

## 작업 규칙

- 화면은 `src/design-system` 배럴의 표준 컴포넌트로 조립한다. **PAGE 서비스는 아직 표준 컴포넌트가 없어 이 화면은 전부 임시 조립**이고, 설명에 「디자인시스템 요청 대상」으로 남겨 뒀다.
- 설명(`body`)은 기능 정의·규칙·예외 케이스로 쓴다. 컴포넌트명·색·px는 쓰지 않는다.
- 작업은 브랜치 → PR. `main` 직접 push 금지.
