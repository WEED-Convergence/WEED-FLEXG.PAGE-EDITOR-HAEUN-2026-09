# FLEXG 어드민 — 디자인관리 > 기본설정 UI/UX 개편

「쇼핑몰 정책 및 기능」 영역을 다시 구성하는 기획 문서 프로토타입.
개편 화면을 실제로 눌러 보면서, 각 영역의 기능 정의·규칙·예외 케이스를 옆에서 함께 읽는다.

> 작성 : 컨버전스 김희연 / 2026.08.26

## 무엇을 다루나

기능 사용 여부와 세부 값이 한 줄에 뒤섞여 있던 설정 목록을, **카테고리 탭 7개 + 상태 토글**로 나눠 다시 구성한다.

| | As-Is | To-Be |
| --- | --- | --- |
| 목록 구조 | 한 페이지에 평면 나열 | 카테고리 탭 7개 · 가나다순 · 초성 인덱스 |
| 설정명 | `기능_이벤트 효과` | `이벤트 효과` |
| 사용 여부 | 옵션 목록에 섞임 (`사용안함 / 벚꽃 / 눈`) | 상태 토글로 분리 (`해제` + `벚꽃 / 눈`) |
| 토글 표기 | 좌우 `OFF ●— ON` | 상태 라벨 내장 `사용` / `해제` |
| 도움말 | 옵션 오른쪽 같은 줄 | 옵션 아래 별도 줄 |

**개편 범위는 기본설정 페이지 최상단 「쇼핑몰 정책 및 기능」 한 영역**이고, 그 아래 5개 영역(쇼핑몰 정보 · 플로팅 액션 버튼 설정 · 쇼핑몰 하단 안내 · 회사소개 · SNS 링크)은 현행 유지다.

## 정리한 판단

시안에 없거나 어긋나던 부분은 이렇게 정해서 문서와 화면에 반영했다.

| 항목 | 정한 것 |
| --- | --- |
| 5개 탭의 항목 배분 | 전체 탭의 순서에서 성격별로 걸러 내는 규칙으로 구성. 이 규칙으로 뽑은 화면·노출 7건이 Figma 시안과 순서까지 일치해 검증됨 |
| 시안에 없던 설정 6개 | 성격에 맞는 탭과 위치에 넣음. 재고옵션 품절 숨김은 상품·장바구니, 선물하기 2건은 주문·결제, 비밀번호 주기와 로그인 실패 잠금은 회원관리, 취소/반품 재고 처리 - 미입금은 정산·재고 |
| 유료서비스 전환 | 탭 목록에서 빼고 설정 영역 맨 아래 안내줄로. 켜고 끄는 설정이 아니라 계약 상태를 알리는 문구 |
| 1:1 문의버튼 | 고객 소통 창구라 회원관리 탭 |
| 하위 설정 계층 | `ㄴ` 문자 대신 들여쓰기와 세로선으로 표시 |
| 부모를 껐을 때 하위 | 옅게 표시하고 조작을 막되 값은 보관 |
| 재고 차감 기준 경고 | 무통장과 가상계좌는 무조건 차감된다는 경고를 그대로 유지 |
| 탭바 노출 둘 다 해제 | 어디에도 노출되지 않는다는 안내를 붙임 |
| 기존 영역 토글 | 이번 범위는 설정 영역만. 나머지는 다음 차수 |

## 작업 규칙

- 화면은 `src/design-system` 배럴의 표준 컴포넌트로 조립한다. 없으면 프로토타입 안에서 임시 조립하고 설명에 「디자인시스템 요청 대상」으로 남긴다.
- 설명(`body`)은 기능 정의·규칙·예외 케이스로 쓴다. 컴포넌트명·색·px는 쓰지 않는다.
- 작업은 브랜치 → PR. `main` 직접 push 금지.
